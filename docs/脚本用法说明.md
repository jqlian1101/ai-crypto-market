# 行情脚本用法说明

本文档说明 `scripts/` 下两个行情脚本的用法：补数脚本 `backfill_market.py` 与校验脚本 `verify_market_candles.py`。

以下命令均在仓库根目录执行，使用项目虚拟环境 `.venv`。

---

## 一、前置条件

1. 启动 PostgreSQL 与 Redis：

   ```powershell
   docker compose up -d
   ```

2. `.env.local` 中配置 `DATABASE_URL`（数据库用户为 `aicrypto`）与 `REDIS_URL`。
3. 数据库迁移到最新版本：

   ```powershell
   .\.venv\Scripts\python.exe -m alembic -c migrations\alembic.ini upgrade head
   ```

4. 运行机器能访问 `api.binance.com` 与 `fapi.binance.com`。两个脚本都使用 Binance 公共接口，无需 API Key。

---

## 二、补数脚本 `scripts/backfill_market.py`

从 Binance 公共 REST 接口分页拉取已收盘 K 线，幂等写入 `market_candles`，`source` 固定为 `REST_BACKFILL`。

### 用法

```powershell
# 演练：只拉取与校验，不写库
.\.venv\Scripts\python.exe scripts\backfill_market.py --days 7 --dry-run

# 正式写入最近 7 天
.\.venv\Scripts\python.exe scripts\backfill_market.py --days 7

# 只补指定标的、市场与周期
.\.venv\Scripts\python.exe scripts\backfill_market.py --symbols BTCUSDT --market-types SPOT --timeframes 1h --days 3
```

### 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--symbols` | `MARKET_SYMBOLS` 配置项 | 逗号分隔，如 `BTCUSDT,ETHUSDT` |
| `--market-types` | `MARKET_TYPES` 配置项 | 可选 `SPOT`、`USDM_FUTURES` |
| `--timeframes` | `MARKET_TIMEFRAMES` 配置项 | 可选 `1m`、`5m`、`15m`、`1h`、`4h` |
| `--days` | `7` | 从当前时间向前补的天数，必须大于等于 1 |
| `--dry-run` | 关闭 | 只拉取与校验，不写库 |

### 行为说明

- 只写已收盘 K 线。未收盘的最后一根会被排除。
- 重复执行安全。主键冲突时以 REST 数据覆盖已有行。
- 单组（市场 × 标的 × 周期）失败不会中断其余组。失败项会记录日志并计入失败数。
- 写入前校验 OHLC 与非负量。非法行会被拒绝并计入失败数。
- 请求之间固定间隔 0.25 秒，避免触发限速。
- 偶发的 SSL 或网络错误可直接重跑，结果是幂等的。

### 退出码

- `0`：全部成功。
- `1`：存在失败组，或参数非法。

## 三、校验脚本 `scripts/verify_market_candles.py`

只读检查 `market_candles` 数据质量，可重复执行，不会修改数据。

### 用法

```powershell
# 仅查数据库，约 1 秒
.\.venv\Scripts\python.exe scripts\verify_market_candles.py

# 额外抽样每组最新 N 根，与 Binance 逐字段比对
.\.venv\Scripts\python.exe scripts\verify_market_candles.py --sample 3
```

### 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--sample N` | `0`，不比对 | 每组抽样最新 N 根，与 Binance 的 OHLCV、成交笔数逐字段比对 |

### 检查项

1. 重复 `open_time`。
2. 未收盘 K 线（`close_time > now`）。
3. OHLC 与非负量非法行。
4. 来源不是 `REST_BACKFILL` 的行。
5. 相邻 `open_time` 之间的缺口。
6. 抽样与 Binance 不一致（仅 `--sample` 时执行）。

每组输出一行结果。有问题的组以 ERROR 级别输出具体项。

### 退出码

- `0`：全部通过。
- `1`：存在失败项。

可用于定时任务或 CI。

---

## 四、推荐流程

```powershell
.\.venv\Scripts\python.exe scripts\backfill_market.py --days 7
.\.venv\Scripts\python.exe scripts\verify_market_candles.py --sample 3
```

先补数，再校验。两步都返回 `0` 即为通过。
